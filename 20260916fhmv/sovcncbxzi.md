# 受试者招募丨高尿酸血症病友请进~

> 更新时间：2026-09-16 (UTC+8)

**尊敬的患者及其家属：**

广西国际壮医医院内分泌代谢病科正在进行**降尿酸复合菌对初诊无症状高尿酸血症患者血尿酸水平影响**的临床研究，计划在全区招募38名符合条件的志愿者参加。

本研究采用肠道降尿酸益生菌为受试制剂，以肠道益生元作为对照制剂，方案已获医院医学伦理委员会批准。

**招募条件**

1. 受试者理解研究方案，自愿参加本研究，并书面签署知情同意书；

2. 年龄在18~70岁之间（包含18和70岁，男女不限）；

3. 初次发现高尿酸血症，之前未接受过相关治疗；

4. 受试者没有长期大量饮酒的习惯（大量饮酒的定义为：饮用酒精量男性>70g/天，女性>40g/天）、没有长期接受抗生素、糖皮质激素、免疫抑制剂等药物治疗；

5. 受试者没有重大疾病病史，未患或已有效控制高血压、糖尿病、消化道溃疡等慢性疾病；

6. 受试者愿意且能够按研究要求按时随访、坚持治疗计划、完成实验室检查以及其它的研究步骤。
